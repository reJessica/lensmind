# 固定模型与设置页交接

更新日期：2026-11-25。更新人：ya.liu（AI 辅助：Codex）。

## 固定方案

| 功能 | 推荐模型 | 设置页其他选项 |
| --- | --- | --- |
| LLM 与画面分析 | `qwen3.5-flash-2026-02-23`，百炼 OpenAI 兼容接口，关闭思考 | 汇云 `qwen3.5-27b`、致远一号 `qwen`、自定义受限域名接口 |
| ASR | `fun-asr-realtime-2026-02-28`，北京地域 | 浏览器语音识别 |
| TTS | `qwen-audio-3.1-tts-flash`，北京地域 | 浏览器语音播报 |
| 云端音色 | `longanhuan_v3.1` | 固定，不自动轮换 |

前端预设位于 `static/js/model-presets.js`，后端语音 ID 由 `SpeechController` 校验。TTS 固定系列型号，未在这里提供日期快照，不能声称服务内部版本永久不变。升级须显式修改并验证。旧用户的汇云配置迁移保留；新用户默认填入推荐 LLM，语音默认使用浏览器，页面加载不产生推理费用。

## 使用步骤

1. 启动 Spring Boot，打开顶部「设置」。
2. LLM 选择「推荐 · Qwen3.5 Flash 固定快照」，填入拥有对应模型权限的百炼 Key，点「测试并连接」。测试发送一张生成的色块，并计入真实调用尝试。
3. 分别选择云端 ASR、TTS，也可混合使用浏览器与云端。云端填写**北京地域** API Key 与 Workspace ID，点「保存语音配置」。Workspace ID 在百炼控制台的业务空间中查看，不能填名称或网址。
4. 保存仅创建本机会话，**不访问供应商，不代表鉴权已验证**。点「试听播报」才调用所选 TTS；返回拍摄页开启麦克风后才采集音频并调用所选 ASR。浏览器选项即时生效，云端选择需先保存会话。
5. 首次只录一条短指令、试听一句话，再检查用量。错误明确显示，不自动重试、换模型或转浏览器。

摄影与语音分别保存密钥，不复用汇云/UniAPI 的 Key，断开一个连接不影响另一个。密钥只在后端会话内存保留，最多 30 分钟；提交、离开设置、切到后台时清空浏览器中的输入，服务重启后需重新填写。同一 Workspace 的有效语音会话可在密钥留空时沿用 Key，更换 Workspace 必须重新填写。

## 当前实际链路

- 浏览器识别沿用 Web Speech API，可能依赖浏览器提供方的网络服务。
- 云端 ASR：AudioWorklet 采集 PCM，能量阈值断句，约 650 ms 静音后提交，持续讲话约 10 秒切段。重采样为 16 kHz 单声道 PCM WAV，上传后端，再通过官方 WebSocket run-task 协议调用固定 Fun-ASR。只接受最终句子并去重，服务端最大 15 秒。
- 文字进入现有 `runCommand`；停止、快门和明确构图口令走本机规则，普通咨询交给已连接 LLM。语音服务不直接控制设备。
- 云端 TTS：后端通过官方 WebSocket 合成 MP3，完整短句返回浏览器后播放；最多 160 字，语速 0.8～1.2，音量由播放器控制。
- **尚未实现端到端逐字识别、逐块播放、连接复用或 LLM 流式播报**，不能用供应商首包延迟宣称项目达到相同延迟。
- 播报期间暂停识别以避免回声，此时可用页面「停止」或 Esc 中断。停止、切后台、离开拍摄页会关闭采集并丢弃待返回结果、停止播放；已发送给供应商的请求仍可能处理或计费。

## 费用与验证边界

摄影会话的连接测试/分析、新语音会话 ASR/TTS 和旧接口的 LIVE 调用共享 `LiveCallBudget`：默认每进程 8 次尝试、并发 2、无自动重试，重启清零。次数不是金额预算，设置页服务状态显示尝试次数。

旧 `/api/ai/status` 的 `MOCK/LIVE` 控制旧版独立接口。工作台临时摄影/语音会话由用户手动配置并激活，主动调用云端时访问真实模型；加载页面、查看状态、保存语音配置不会产生推理调用。

已用模拟客户端验证协议、会话隔离、音频格式和取消行为，尚未使用真实百炼 Key/Workspace 验证本套模型的权限、音质和实际延迟。桌面浏览器工具连接超时，真实录音、播放和窄屏流程需要补测。
