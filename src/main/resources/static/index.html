        使用说明

        1. 点「开始拍摄」，在拍摄页开启电脑摄像头，或使用演示画面。
        2. 选「构图辅助」按提示调整位置，或选「手动拍摄」自己决定何时按快门。可以直接拖动裁剪框。
        3. 在「摄影助手」点一次麦克风即可开启持续监听和播报。听到「可以拍了」后直接说「拍摄」，也可以说「已完成」结束动作指导，或说「停止」取消倒计时。
        4. 点「拍一张照片」，倒计时结束时取景。按 Esc 或点「停止」会取消当前操作，模拟机位复位后可以继续拍。
        5. 点「完成拍摄」关闭摄像头并进入选片页。照片只保存在当前页面，刷新或关闭前请下载。
