    欢迎使用灵眸

    这是团队协作的初始框架。默认使用本地插画作为取景场景，所有机位操作都是模拟，不会控制真实机械臂。

    1. 选择构图和比例，拖动裁剪框调整保留范围。
    2. 输入“拍照”或按拍摄按钮，等待倒计时。
    3. 点击照片编辑裁剪，分别下载原片和成片。
    4. 按 Esc 或“停止”取消当前操作；回初始位后恢复。

    语音识别取决于浏览器支持与麦克风权限，可能使用浏览器提供方的在线服务；文字输入始终可用。电脑摄像头仅在你点击并授权后开启，真实摄像头模式尚无人物识别或自动稳定检测。

    “放大一点”只做数字裁剪。“相机靠近一点”等三维移动需要未来的硬件规划接口。人物指导为预设文案，点击完成后才会继续。
